# 個人網站開發方向

以下為建議方向，尚未決定實作。評估日期：2026-10-11。

## 現況與目標

- **現況：**英文自我介紹、公開服務入口與 GitHub 連結；設計簡潔，方便查找服務。
- **缺口：**訪客看不出站主的參與角色、成果與技術思考。
- **目標：**發展成精簡的個人作品集。保留服務入口，詳細案例與文章放在獨立頁面。
- **讀者：**初期以同儕與潛在合作對象為主；若改以求職或研究交流為目標，再調整內容重心。

## 可新增的內容

| 方向       | 內容                                                                                   | 維護需求             |
| ---------- | -------------------------------------------------------------------------------------- | -------------------- |
| 精選作品   | 先做兩個代表案例：問題、個人貢獻、做法、成果、截圖與公開連結；區分開發、協作與代管角色 | 專案變動時更新       |
| 個人介紹   | 關注領域、歡迎的合作方式；視需要加入經歷、履歷或聯絡方式                               | 定期檢視             |
| 技術文章   | 公開專案的決策、開發經驗與學習筆記                                                     | 持續寫作             |
| 近況與興趣 | 學習近況、閱讀筆記或工具心得                                                           | 有穩定更新習慣再加入 |
| 互動展示   | 與作品相關的遊戲機制、演算法視覺化或小工具                                             | 開發與維護成本較高   |
| 服務狀態   | 有需求時優先連到既有的公開狀態頁                                                       | 自建監測需持續維運   |

## 設計方向

已決定採用 Material UI，規範見 [AGENTS.md](../AGENTS.md#rules)。以下為版面風格選項：

| 選項                 | 特色                                       | 取捨                   |
| -------------------- | ------------------------------------------ | ---------------------- |
| 編輯式作品集（建議） | 延續中性色與青綠色，強化自我介紹與作品預覽 | 改動適中，容易擴充文章 |
| 視覺作品展示         | 大截圖與作品網格                           | 需要品質一致的視覺素材 |
| 開發者筆記           | 文章、作品摘要與技術示意圖為主             | 需以持續寫作為網站重心 |

首頁順序：自我介紹 → 精選作品 → 公開服務 → 個人連結；有文章後再加入近期筆記。採用柔和暗灰色背景，並清楚區分作品閱讀入口與服務操作入口。

## 開發優先順序

1. **P1 個人特色與作品：**確認目標讀者，完成兩個代表案例，改善自我介紹與服務入口，加入作品預覽與基本分享資訊。
2. **P2 文章與背景：**第一批文章完成後，加入 RSS（文章列表已完成，撰寫方式見 [writing.md](writing.md)）；依讀者需求補上「關於我」或履歷。
3. **P3 依需求擴充：**互動展示、近況頁或服務狀態擇一推進；文章累積後才考慮搜尋。

## 範圍限制

- 維持英文單語與靜態網站架構，只使用可公開的作品資料；其餘規範見 [AGENTS.md](../AGENTS.md#rules)。
- 留言、帳號、聯絡表單後端、即時外部元件與流量分析，等有明確需求再評估。
